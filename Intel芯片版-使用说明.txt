WorkBuddy 第三方 AIP 对接工具 V1.22
Intel 芯片版（macOS Ventura 13 及以上）

【正确安装】
1. 必须下载完整 ZIP，不要单独复制 .app 文件。
2. 使用 macOS 自带“归档实用工具”解压 ZIP。
3. 将“WorkBuddy第三方AIP对接工具-Intel芯片.app”拖入“应用程序”。
4. 第一次启动请右键应用，选择“打开”，再点击“打开”。

【如果仍提示无法打开】
1. 回到解压后的文件夹。
2. 右键“Intel芯片版-首次启动修复.command”，选择“打开”。
3. 终端会自动修复执行权限、移除本次下载的隔离标记并重新签名，然后启动应用。

如果 macOS 仍然拦截：
系统设置 → 隐私与安全性 → 安全性 → 找到该应用 → 点击“仍要打开”。

说明：
- 应用启动后会弹窗询问是否打开“隐私与安全性”，也可点击窗口右上角“隐私设置”。
- 使用圆形苏苏 SS 图标，圆形以外区域透明。
- 该工具不需要摄像头、麦克风、屏幕录制或辅助功能权限。
- “隐私与安全性”提示属于 macOS 对未公证第三方应用的 Gatekeeper 保护，不是工具在读取隐私数据。
- v1.4 修复包由 macOS Intel 构建机直接使用 ditto 打包，保留 .app 主入口执行权限；请勿在 Windows 上解压后重新压缩。
- 内置 certifi/Mozilla 可信 CA 证书包，OpenKun 拉取模型和连接测试使用严格证书与主机名校验。
- V1.22 修复 OpenKun 拉取模型时的 macOS TLS `UNEXPECTED_EOF_WHILE_READING`；优先使用严格 TLS，只有该特定 EOF 才安全回退到 macOS 系统网络栈。
- API Key 保存到当前 macOS 用户的系统钥匙串；providers.json 仅保存钥匙串引用。JSON 导出默认不包含 API Key。
- 远程 API 必须使用 HTTPS，只有 localhost 本地服务允许 HTTP。
- 工具数据位于 ~/.workbuddy/workbuddy-aip/，WorkBuddy 模型文件位于 ~/.workbuddy/models.json。
