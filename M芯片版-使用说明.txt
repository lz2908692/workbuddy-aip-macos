WorkBuddy 第三方 AIP 对接工具 V1.22
M 芯片版（Apple Silicon M1/M2/M3/M4）

【正确安装】
1. 必须下载完整 ZIP，不要单独复制 .app 文件。
2. 使用 macOS 自带“归档实用工具”解压 ZIP。
3. 将“WorkBuddy第三方AIP对接工具-M芯片.app”拖入“应用程序”。
4. 第一次启动请右键应用，选择“打开”，再点击“打开”。

【隐私与安全性】
- 应用启动后会弹窗询问是否打开“隐私与安全性”，也可点击窗口右上角“隐私设置”。
- 若应用尚未成功启动，请运行同目录的“M芯片版-首次启动修复.command”。它会打开“隐私与安全性”，请在安全性区域点击“仍要打开”。

【说明】
- 使用圆形苏苏 SS 图标，圆形以外区域透明。
- V1.22 修复 OpenKun 拉取模型时的 macOS TLS `UNEXPECTED_EOF_WHILE_READING`；优先使用严格 TLS，只有该特定 EOF 才安全回退到 macOS 系统网络栈。
- API Key 保存到当前 macOS 用户系统钥匙串；JSON 导出默认不包含 API Key。
- 远程 API 必须使用 HTTPS，只有 localhost 本地服务允许 HTTP。
- 工具数据位于 ~/.workbuddy/workbuddy-aip/，WorkBuddy 模型文件位于 ~/.workbuddy/models.json。
