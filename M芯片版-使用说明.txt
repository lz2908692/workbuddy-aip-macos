WorkBuddy 第三方 AIP 对接工具 V1.24
M 芯片版（Apple Silicon M1/M2/M3/M4）

【正确安装】
1. 必须下载完整 ZIP，不要单独复制 .app 文件。
2. 使用 macOS 自带“归档实用工具”解压 ZIP。
3. 将“WorkBuddy第三方AIP对接工具-M芯片.app”拖入“应用程序”。
4. 第一次启动请右键应用，选择“打开”，再点击“打开”。

【隐私与安全性】
- 尚未成功读取模型名称时，应用启动会提示“隐私与安全性”；一旦成功拉取至少一个模型名称，后续启动不再自动弹窗。右上角“隐私设置”按钮始终保留。
- 若应用尚未成功启动，请运行同目录的“M芯片版-首次启动修复.command”。修复程序只处理权限、隔离标记和签名，不再重复打开系统设置。

【说明】
- V1.24 修复 Dock 双图标；应用改用 macOS 推荐的目录式 .app，并让 Bundle 与运行态统一使用同一个蓝色苏苏 SS 图标。
- 苏苏图标仅保留蓝色原图标主体，灰色方框背景已改为完全透明。
- V1.22 修复 OpenKun 拉取模型时的 macOS TLS `UNEXPECTED_EOF_WHILE_READING`；优先使用严格 TLS，只有该特定 EOF 才安全回退到 macOS 系统网络栈。
- V1.23 增强 API Key 认证诊断：空 Key 不再请求；自动清理重复的 Bearer 前缀；HTTP 401 会明确提示重新输入有效 Key 并保存；日志只显示 Key 长度和不可逆短指纹。
- 若出现 HTTP 401：重新复制 OpenKun 当前有效 API Key 到输入框，点击“保存配置”，确认日志显示“API Key：已配置”，再点击“拉取模型”。
- API Key 保存到当前 macOS 用户系统钥匙串；JSON 导出默认不包含 API Key。
- 远程 API 必须使用 HTTPS，只有 localhost 本地服务允许 HTTP。
- 工具数据位于 ~/.workbuddy/workbuddy-aip/，WorkBuddy 模型文件位于 ~/.workbuddy/models.json。
